# `PYTHON // CLASSES & POO`

Repositório dedicado à implementação progressiva de conceitos de Programação Orientada a Objetos (POO), modelagem de classes, atributos, métodos, encapsulamento e integração de objetos em **Python**.

## 🗺️ Roadmap de Estudos e Práticas

* [x] **Fase 1**: Modelagem básica de classes, construtores (`__init__`) e instanciação de objetos.
* [x] **Fase 2**: Métodos especiais, encapsulamento de atributos e validação de estados.
* [x] **Fase 3**: Lógica avançada de métodos, herança e integração entre múltiplos objetos.
* [ ] **Fase 4**: Polimorfismo, classes abstratas e tratamento de exceções customizadas.

## 📁 Arquivos Principais

* **`exercises_1.py`**: Estrutura base de classes, criação de construtores, definição de atributos e primeiros testes de instanciação.
* **`exercises_2.py`**: Implementação de métodos especiais (como representação e manipulação de estado), validação interna de dados e encapsulamento.
* **`exercises_3.py`**: Evolução da modelagem de classes, lógica avançada de métodos e integração complexa entre objetos.
